One line of office comedy: "I replied-all to 400 people saying 'please stop replying all' and became the incident I was reporting." The joke turns on a ritual anyone who has worked in an office knows — the reply-all storm — and holds its payoff to the last words, where the complainer becomes the incident they were reporting. The program in `main.ts` (Node 22, standard library only) writes that single joke, byte-identically on every run, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` anywhere else), clearing only the directory's contents first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
